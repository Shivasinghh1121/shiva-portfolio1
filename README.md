# Shiva Singh — Personal Portfolio

A beginner-friendly, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## About
- **Name:** Shiva Singh
- **Course:** B.Tech Computer Science
- **Institute:** KIET Group of Institutions, Ghaziabad
- **Year:** 1st Year

## Features
- Responsive layout for desktop and mobile
- Home, About, Education, Skills, Projects, and Contact sections
- Mobile navigation menu
- Automatically updated footer year

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

## Before publishing
1. In `index.html`, replace `your-email@example.com` with your real email address in the `mailto:` link and reminder text.
2. Update the skills and project cards as you learn and complete more work.
3. Add your real GitHub and LinkedIn links if you want them displayed.

## Files
- `index.html` — page structure and content
- `style.css` — design and responsive styling
- `script.js` — mobile menu and footer year
